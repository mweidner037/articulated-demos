# Collaborative Folder Tree

A real-time collaborative folder tree demo using [Articulated](https://github.com/mweidner037/articulated).

## Setup

```sh
npm i
```

## Development

```sh
npm run dev
```

Then open http://localhost:5566 in multiple browser windows to test collaboration.

## Production

```sh
npm run build
```

```sh
npm run start
```
